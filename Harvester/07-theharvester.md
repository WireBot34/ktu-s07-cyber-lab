# Experiment: theHarvester

## Aim
To collect publicly available domain-related information using theHarvester.

## Requirements
- Kali Linux or another compatible environment
- theHarvester
- Internet access and any required API keys
- An authorized lab domain

## Theory
theHarvester is an OSINT tool that gathers information such as
publicly indexed email addresses, hostnames, and names from supported
search engines and other configured sources.

## Procedure
1. Verify the installation:
   ```bash
   theHarvester -h
   ```
2. Review the help output and available data sources.
3. Select a permitted source and an authorized lab domain.
4. Run the query using the syntax documented by the installed version.
5. Review the returned information.
6. Distinguish verified findings from unconfirmed results.
7. Save the results in an appropriate report format.
