# Experiment: Maltego

## Aim
To study relationship-based OSINT using Maltego.

## Requirements
- Maltego Community Edition or an authorized edition
- Internet connection
- An approved investigation target

## Theory
Maltego is an OSINT and link-analysis tool that represents entities
and their relationships in a visual graph. Transforms can retrieve
information from supported data sources.

## Procedure
1. Install and open Maltego.
2. Sign in or configure the required edition.
3. Create a new graph.
4. Add an appropriate entity, such as an authorized domain.
5. Review the available transforms.
6. Run permitted transforms against the lab target.
7. Examine the resulting entities and relationships.
8. Save the graph and document the findings.
