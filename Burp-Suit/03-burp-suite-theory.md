# Experiment: Burp Suite – Theory

## Aim
To understand Burp Suite and its role in web application security testing.

## Requirements
- Burp Suite Community Edition or an authorized edition
- A browser
- A deliberately vulnerable local web application

## Theory
Burp Suite is a web application security testing platform. Its tools
include a proxy for inspecting HTTP traffic, Repeater for manually
resending requests, and other features for authorized testing.

## Procedure
1. Open Burp Suite and create a temporary project.
2. Start the built-in browser or configure a test browser's proxy.
3. Visit the local lab application.
4. Inspect requests and responses in the HTTP history.
5. Send a selected test request to Repeater.
6. Modify harmless test parameters and compare responses.
7. Record observations without testing systems outside the lab.

## Precautions
- Test only applications you own or are authorized to assess.
- Do not capture unrelated users' traffic.
- Avoid destructive requests and production data.
